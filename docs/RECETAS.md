# Recetas — cantidades por ración adulta

Cantidades **por ración adulta** en unidad base (g / ml / ud). El total de la compra se
obtiene multiplicando por las raciones (14 + 3×0,5 = **15,5**) — ver README.

Un niño = 0,5 raciones (configurable en `data/Config.csv`).
